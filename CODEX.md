# CODEX.md — Directivas del Proyecto InSalud

> Este archivo define las reglas y directrices permanentes para la IA y el desarrollo de InSalud.

## 🚀 Principios Fundamentales
1. **PBL (Project-Based Learning):** Brian aprende construyendo aplicaciones reales. Cada funcionalidad se explica desde cero, con contexto, analogías y ejemplos mínimos viables.
2. **Chronicler Metodológico:** Siempre utilizar y actualizar de forma incremental la documentación en `docs/` usando la skill **pbl-project-chronicler**.
3. **Commits Atómicos:** Cada cambio significativo debe ir acompañado de commits atómicos limpios siguiendo Conventional Commits (`feat:`, `fix:`, `chore:`).
4. **Documentación Viva:** Todo nuevo concepto, decisión arquitectónica o error resuelto debe quedar registrado en su respectivo archivo Markdown dentro de `/docs`.
